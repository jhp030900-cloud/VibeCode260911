HTML5 CSS3 JavaScript 실습

HTML5, CSS3, JavaScript를 한 번에 배우기

웹페이지를 만들 때 필요한 기본 기술을 이해하고, 예제와 실습으로 직접 눈으로 확인해보세요. 짧은 시간 안에 구조, 스타일, 동작을 연결하는 방법을 익힐 수 있습니다.

실습 시작 기초 보기

핵심 개념

  • HTML: 내용을 구성하는 뼈대
  • CSS: 화면을 꾸미는 스타일
  • JavaScript: 반응과 동작을 추가
HTML5

문서 구조

  • 제목, 문단, 링크, 이미지, 표, 리스트를 만들 수 있어요.
  • 웹 페이지의 의미와 구조를 정리하는 역할을 합니다.
  • 시맨틱 태그로 더 의미 있는 문서를 만들 수 있어요.
CSS3

디자인 꾸미기

  • 색상, 간격, 배치, 글꼴, 애니메이션 등을 설정합니다.
  • 반응형 레이아웃으로 모바일 화면에도 대응할 수 있어요.
  • 클래스와 선택자를 활용해 스타일을 관리합니다.
JavaScript

동작 추가

  • 버튼 클릭, 입력값 처리, 시간 표시 등을 구현합니다.
  • 사용자와의 상호작용을 가능하게 합니다.
  • 조건문, 함수, 배열 등으로 프로그램처럼 동작합니다.

기본 예제

HTML 예시

<h1>안녕하세요!</h1>
<p>HTML은 페이지의 내용을 구성합니다.</p>
<button>클릭</button>

CSS 예시

h1 {
  color: #2563eb;
  text-align: center;
}

button {
  background: #10b981;
  color: white;
  padding: 10px 20px;
}

간단한 실습

메시지: 버튼을 눌러 웹 페이지가 반응하는 것을 확인해보세요.
